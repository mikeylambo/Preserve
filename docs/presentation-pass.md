# Presentation pass — 2026-10-08

Implemented the six-second opening (drip, glass crack, spill and awakening), four-second lift, eight-second surface escape, five-second farmhouse reveal, and forty-second homecoming (rim pause, pour, lid, label, pullback). The homecoming leads to a scorecard and credits; the saved death map scrolls with motion enabled. All sequences can be skipped. Homecoming can be replayed from post-game title/credits. Reduced motion uses a fixed camera and suppresses incidental weather/particles while retaining necessary story actions.

The shared painted fruit label and farmhouse photo are generated from original canvas artwork. Concrete, timber and cloth have deterministic painted surface textures. Gel geometry is rounded, with soft material skins, contact rings, droplets and emissive material accents. Architecture gains desks, mugs, vents, rivets, pictograms and light shafts; the surface has rain. Cinematics add morning light, tabletop cloth, a furnished jar, farmhouse siding, window trim, fences, a path and trees. Repeated background geometry is batched.

The original score uses a recurring sixteen-note motif with different arrangements: sparse heartbeat/pad for Intake, glass plucks for red-light acts, mechanical rhythm for Compression/Cryogenic, felt-inspired piano for Separation/Power, modeled plucked strings for the Surface, and a warm piano/string/music-box arrangement for Home. Distinct wet, puncture, sizzle, frost, press and electrical layers accompany material events. Reverb and a master compressor provide headroom; all four volume buses remain independent. No downloaded music, commercial samples or reused image assets were added.

Validation: 33 deterministic gameplay/replay tests pass, including protected prototype movement and 50 shipped clear tapes. Browser checks cover opening and ending handoffs, ending timeline landmarks, scorecard/credits, replay and skip, all three between-act transition handoffs, offline boot with zero HTTP requests, touch skip/pause/settings/resume with reduced motion, and emulated controller confirm/back-to-skip. All 101 room scenes render without browser errors; maximum measured gameplay draw calls were 54, triangles 136352, under headless software rendering. These measurements do not certify hardware frame rate. The combined cue/arrangement offline audio render has finite output, peak 0.411 and RMS 0.0204; this checks signal integrity rather than subjective sound quality.

Presentation remains a polish pass on the playable alpha. Full later-campaign validation, physical-device review, final art/music direction and public leaderboard deployment remain separate work. Movement, hazards, room layouts, pars and replay version were preserved.

Optional browser QA: install Playwright and its Chromium browser separately, then run `node tests/browser-presentation.cjs`. This harness uses presentation-only teleports to trigger ending/transition checks; it does not certify room solutions. `PRESERVE_CHROMIUM`, `PRESERVE_PLAYWRIGHT`, and `PRESERVE_QA_OUTPUT` can select local browser/module/output paths.
